# Getting support

Thanks for using Forge. Please use the right channel so we can help quickly.

| I want to… | Channel |
| --- | --- |
| **Report a bug** | [Bug report issue](https://github.com/RodiumAi/Forge/issues/new?template=bug_report.yml) |
| **Request a feature** | [Feature request issue](https://github.com/RodiumAi/Forge/issues/new?template=feature_request.yml) |
| **Propose a template kit** (site, app, slides, codelab or design system) | [Template proposal issue](https://github.com/RodiumAi/Forge/issues/new?template=template_proposal.yml) |
| **Propose an integration** | [Integration proposal issue](https://github.com/RodiumAi/Forge/issues/new?template=integration_proposal.yml) |
| **Report a security vulnerability** | **Privately**: [report a vulnerability](https://github.com/RodiumAi/Forge/security/advisories/new) on GitHub, or email forge@rodiumai.io if you cannot use GitHub. See [SECURITY.md](SECURITY.md). Never open a public issue. |
| **Report a Code of Conduct concern** | Privately by email to forge@rodiumai.io. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |
| **Contribute code, docs or templates** | Read [CONTRIBUTING.md](CONTRIBUTING.md) first |
| **Set up or self-host Forge** | [README](README.md), the [Docker guide](DOCKER.md) and the [docs index](docs/README.md) |

Before opening an issue, please search the
[existing issues](https://github.com/RodiumAi/Forge/issues) to avoid
duplicates. Blank issues are disabled: use one of the templates above.

This is an open-source project maintained on a best-effort basis; there is no
paid support SLA.
