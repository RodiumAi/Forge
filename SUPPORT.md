# Getting support

Thanks for using Forge. Please use the right channel so we can help quickly.

| I want to… | Channel |
| --- | --- |
| **Report a bug** | [Bug report issue](https://github.com/RodiumAi/Forge/issues/new?template=bug_report.yml) |
| **Request a feature** | [Feature request issue](https://github.com/RodiumAi/Forge/issues/new?template=feature_request.yml) |
| **Propose a template kit** | [Template proposal issue](https://github.com/RodiumAi/Forge/issues/new?template=template_proposal.yml) |
| **Report a security vulnerability** | **Privately** — [Report a vulnerability](https://github.com/RodiumAi/Forge/security/advisories/new) or email forge@rodiumai.io. See [SECURITY.md](SECURITY.md). Never open a public issue. |
| **Report a Code of Conduct concern** | Privately by email: forge@rodiumai.io — see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| **Contribute code / docs / templates** | Read [CONTRIBUTING.md](CONTRIBUTING.md) first |
| **Set up or self-host Forge** | [Docker guide](DOCKER.md) and [docs/](docs/) |

Before opening an issue, please search [existing issues](https://github.com/RodiumAi/Forge/issues)
to avoid duplicates. Blank issues are disabled — use one of the templates above.

This is an open-source project maintained on a best-effort basis; there is no
paid support SLA.
