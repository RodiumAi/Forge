# Installer Python

:::tabs group="os"
@tab Windows
Téléchargez Python sur python.org et **cochez « Add Python to PATH »** pendant l'installation.

```terminal
PS> python --version
Python 3.12.6
```
@tab macOS
```terminal
$ brew install python@3.12
$ python3 --version
Python 3.12.6
```
:::

Ouvrez ensuite l'éditeur IDLE, installé avec Python.
