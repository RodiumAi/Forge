# Les variables

Une variable est une boîte avec une étiquette.

```py title="bonjour.py"
prenom = "Awa"
age = 12
print("Bonjour", prenom, "tu as", age, "ans")
```

```terminal
$ python bonjour.py
Bonjour Awa tu as 12 ans
```

:::info Exercice
Changez le prénom et l'âge, puis relancez le programme.
:::
