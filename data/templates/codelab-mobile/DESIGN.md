## Colors
- `--bg`: #FFF9F5 (page background)
- `--surface`: #FFF1E8 (sidebar, cards and code headers)
- `--fg`: #2A1A12 (main text)
- `--muted`: #5B6170 (secondary text, line numbers, output)
- `--accent`: #E4572E (links, progress, current step, highlighted lines)
- `--accent-contrast`: #FFFFFF (text on the accent)
- `--border`: #F3DDCF (hairlines, code frames)

## Typography
- Display font: Poppins
- Body font: Inter
- Mono font: JetBrains Mono

## Codelab style
- Tons chauds, coins arrondis.
- Montrer ce que l'on voit sur le téléphone après chaque étape.
