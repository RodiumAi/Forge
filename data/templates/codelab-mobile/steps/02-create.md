# Créer le projet

```terminal
$ npx create-expo-app@latest habitudes
$ cd habitudes
$ npx expo start
Metro waiting on exp://192.168.1.20:8081
```

Scannez le QR code avec Expo Go. L'écran d'accueil vient de `app/index.tsx`.

```tree
habitudes/
  app/
    index.tsx  # premier écran
  assets/
  package.json
```
