# Introduction

Dans ce codelab, vous créez une API REST qui gère une liste de tâches. Elle saura lister, créer et lire des tâches, refuser les données invalides et répondre `404` quand une tâche n'existe pas.

## Ce que vous allez construire

```tree
taches/
  main.py  # l'application FastAPI
  test_main.py  # les tests
  requirements.txt
```

:::info Pourquoi FastAPI ?
FastAPI génère la documentation interactive de votre API à partir du code, et valide les données grâce aux annotations de type.
:::
