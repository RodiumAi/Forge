# Foldspace 3D

Product landing template built around real CSS 3D constructions (preserve-3d cube, hinged folded panels, isometric cards). React 18 + Vite + TypeScript, single-file page in `src/App.tsx`.

- `npm install`
- `npm run dev` — http://localhost:5173
- `npm run build`

See `DESIGN.md` for the design charter.
