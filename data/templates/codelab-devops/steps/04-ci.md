# Intégration continue

Créez `.github/workflows/ci.yml`. Le job `image` ne démarre que si les tests passent (`needs: test`).

```yaml title=".github/workflows/ci.yml" {11-16,19}
name: ci
on:
  push:
    branches: [main]
  pull_request:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.12"
      - run: pip install -r requirements.txt
      - run: pytest -q

  image:
    needs: test
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: docker build -t app:${{ github.sha }} .
```

```terminal
$ git add .
$ git commit -m "ci: tests et image Docker"
$ git push
```

:::info
Ouvrez l'onglet **Actions** de votre dépôt pour suivre l'exécution en direct.
:::
