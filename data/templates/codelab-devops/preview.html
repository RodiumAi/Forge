Écrire le Dockerfile

Vous emballez une API Python dans une image Docker, la lancez avec Docker Compose, puis faites tester et construire chaque commit par GitHub Actions.

codeCopier
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
USER 1000
