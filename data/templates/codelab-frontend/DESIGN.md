# Design charter: Tutoriel frontend

## Template
- id: codelab-frontend
- name: Tutoriel frontend

## Colors
- `--bg`: #FBFAFF (page background)
- `--surface`: #F3F0FF (sidebar, cards and code headers)
- `--fg`: #1B1630 (main text)
- `--muted`: #5B6170 (secondary text, line numbers, output)
- `--accent`: #6D4AFF (links, progress, current step, highlighted lines)
- `--accent-contrast`: #FFFFFF (text on the accent)
- `--border`: #E2DCF7 (hairlines, code frames)

## Typography
- Display font: Space Grotesk
- Body font: Inter
- Mono font: JetBrains Mono

## Codelab style
- Violet vif, interface aérée.
- Toujours montrer le rendu attendu après le code.
