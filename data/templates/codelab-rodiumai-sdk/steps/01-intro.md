# Introduction

L'API RodiumAi est compatible avec le format OpenAI : les SDK officiels OpenAI fonctionnent en changeant simplement l'URL de base. Un seul compte donne accès aux modèles de plusieurs fournisseurs, facturés en **RODI**.

:::info
Toutes les requêtes passent par `https://api.rodiumai.io/v1`.
:::
