# Design charter: Tutoriel data

## Template
- id: codelab-data
- name: Tutoriel data
- kind: codelab

## Colors
- `--bg`: #F7FAFF (page background)
- `--surface`: #EEF3FC (sidebar, cards and code headers)
- `--fg`: #0F1B33 (main text)
- `--muted`: #5B6170 (secondary text, line numbers, output)
- `--accent`: #2563EB (links, progress, current step, highlighted lines)
- `--accent-contrast`: #FFFFFF (text on the accent)
- `--border`: #DCE5F5 (hairlines, code frames)

## Typography
- Display font: IBM Plex Sans
- Body font: IBM Plex Sans
- Mono font: IBM Plex Mono

## Codelab style
- Bleu analytique, tableaux lisibles.
- Toujours afficher la sortie attendue après un calcul.
