# Politique de sécurité

## Versions supportées

Seule la branche principale est supportée. Les correctifs de sécurité y arrivent en premier.

## Signaler une vulnérabilité

Merci de signaler les vulnérabilités en privé via les **GitHub Security Advisories** (« Report a vulnerability » dans l'onglet Security du dépôt), ou par e-mail à **forge@rodiumai.io** si vous ne pouvez pas utiliser GitHub.

- N'ouvrez **pas** d'issue publique pour un problème de sécurité.
- Ne divulguez pas la vulnérabilité publiquement avant la publication d'un correctif.
- Nous accuserons réception de votre signalement, travaillerons sur un correctif et coordonnerons la divulgation avec vous.
