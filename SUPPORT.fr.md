# Obtenir de l'aide

Merci d'utiliser Forge. Passez par le bon canal pour qu'on puisse vous aider vite.

| Je veux… | Canal |
| --- | --- |
| **Signaler un bug** | [Issue Bug report](https://github.com/RodiumAi/Forge/issues/new?template=bug_report.yml) |
| **Proposer une fonctionnalité** | [Issue Feature request](https://github.com/RodiumAi/Forge/issues/new?template=feature_request.yml) |
| **Proposer un kit template** (site, appli, slides, codelab ou design system) | [Issue Template proposal](https://github.com/RodiumAi/Forge/issues/new?template=template_proposal.yml) |
| **Proposer une intégration** | [Issue Integration proposal](https://github.com/RodiumAi/Forge/issues/new?template=integration_proposal.yml) |
| **Signaler une vulnérabilité** | **En privé** : [signaler une vulnérabilité](https://github.com/RodiumAi/Forge/security/advisories/new) sur GitHub, ou par e-mail à forge@rodiumai.io si vous ne pouvez pas utiliser GitHub. Voir [SECURITY.fr.md](SECURITY.fr.md). Jamais d'issue publique. |
| **Signaler un problème de conduite** | En privé, par e-mail à forge@rodiumai.io. Voir [CODE_OF_CONDUCT.fr.md](CODE_OF_CONDUCT.fr.md). |
| **Contribuer du code, de la doc ou des templates** | Lisez d'abord [CONTRIBUTING.fr.md](CONTRIBUTING.fr.md) |
| **Installer ou auto-héberger Forge** | Le [README](README.fr.md), le [guide Docker](DOCKER.fr.md) et l'[index de la documentation](docs/README.md) |

Avant d'ouvrir une issue, cherchez dans les
[issues existantes](https://github.com/RodiumAi/Forge/issues) pour éviter les
doublons. Les issues vierges sont désactivées : utilisez l'un des modèles
ci-dessus.

Projet open source maintenu au mieux de nos disponibilités ; il n'y a pas de
support payant avec SLA.
