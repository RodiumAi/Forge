# Obtenir de l'aide

Merci d'utiliser Forge. Utilisez le bon canal pour qu'on puisse vous aider vite.

| Je veux… | Canal |
| --- | --- |
| **Signaler un bug** | [Issue Bug report](https://github.com/RodiumAi/Forge/issues/new?template=bug_report.yml) |
| **Proposer une fonctionnalité** | [Issue Feature request](https://github.com/RodiumAi/Forge/issues/new?template=feature_request.yml) |
| **Proposer un kit template** | [Issue Template proposal](https://github.com/RodiumAi/Forge/issues/new?template=template_proposal.yml) |
| **Signaler une vulnérabilité** | **En privé** — [Report a vulnerability](https://github.com/RodiumAi/Forge/security/advisories/new) ou e-mail forge@rodiumai.io. Voir [SECURITY.fr.md](SECURITY.fr.md). Jamais d'issue publique. |
| **Signaler un problème de conduite** | En privé par e-mail : forge@rodiumai.io — voir [CODE_OF_CONDUCT.fr.md](CODE_OF_CONDUCT.fr.md) |
| **Contribuer du code / de la doc / des templates** | Lisez d'abord [CONTRIBUTING.fr.md](CONTRIBUTING.fr.md) |
| **Installer ou auto-héberger Forge** | [Guide Docker](DOCKER.fr.md) et [docs/](docs/) |

Avant d'ouvrir une issue, cherchez dans les
[issues existantes](https://github.com/RodiumAi/Forge/issues) pour éviter les doublons.
Les issues vierges sont désactivées — utilisez l'un des templates ci-dessus.

Projet open-source maintenu au mieux ; il n'y a pas de support payant avec SLA.
